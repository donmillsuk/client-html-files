    How to use this without needing a lie down

    Start at the top. For each item, answer Installed / Done or No, show install route. If something is missing, the route opens the official install page and gives the check step. Required items block the main route until marked done. Optional items can be skipped.

    Rule: use official links, Microsoft Store, Ninite, or UniGetUI. Do not install from advert links, “download portals,” driver-updater sites, or anything wearing a fake moustache.
    Best updater path: install UniGetUI early, then use it to scan for app updates after the main installs. Keep Ninite as a simple fallback installer/updater for common apps.
    Local/GitHub note: this file is fully self-contained. You can upload it to GitHub Pages or open it directly from your computer. The progress checkboxes save per browser/device, not inside the HTML file itself. Computers remain annoying, but at least this one is honest.
